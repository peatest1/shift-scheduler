# ระบบจัดเวรพนักงานแก้ไขกระแสไฟฟ้าขัดข้อง

เว็บแอปแบบไฟล์ static ล้วน (HTML/CSS/JS ไม่มีขั้นตอน build) ใช้ **Firebase** (ฟรี) เป็นระบบสมาชิกและฐานข้อมูล
โฮสต์ด้วย **GitHub Pages** (ฟรี) — ตรงกับที่ต้องการ "github + อะไรง่ายๆฟรีๆ"

## สิ่งที่ทำได้ในระบบนี้
- ระบบสมาชิก 2 สิทธิ์: **แอดมิน** (จัดเวรได้ทั้งหมด) และ **พนักงาน** (ดูเวรตัวเองอย่างเดียว)
- จัดการกลุ่มเวร 5 กลุ่มตามไฟล์ต้นฉบับ (แก้ชื่อ/จำนวนช่วงเวรต่อวันได้): พนักงานอยู่เวรชุด 1-3, ผู้ตรวจเวร, พนักงานสั่งการ
- เพิ่ม/ลบ/เลื่อนลำดับพนักงานในแต่ละกลุ่ม (ลำดับมีผลต่อการหมุนเวรอัตโนมัติ)
- ปฏิทินวันหยุด: ดึงวันหยุดราชการไทยจริงอัตโนมัติ (API ฟรี ไม่ต้องขอ key) + เพิ่มวันหยุดพิเศษของหน่วยงานเองได้
- กดปุ่มเดียวสุ่มหมุนเวรอัตโนมัติให้เท่ากันทุกคนในแต่ละเดือน แล้วแก้ไขทีละช่องภายหลังได้ (แบบ dropdown)
- พนักงานล็อกอินดูตารางเวรของตัวเองได้ทันที

### ข้อจำกัดที่ควรทราบ (ทำให้ระบบเรียบง่ายและฟรี)
- การสร้างบัญชีพนักงานทำแบบ "ผูกรหัสพนักงาน": แอดมินเพิ่มชื่อ-รหัสพนักงานในระบบก่อน แล้วพนักงานสมัครสมาชิกเองภายหลังโดยกรอกรหัสพนักงานให้ตรงกัน (ไม่ต้องใช้ Cloud Functions ซึ่งไม่ฟรี)
- การหมุนเวรอัตโนมัติเป็นแบบ "หมุนเวียนเท่าๆ กัน" (round robin) ยังไม่รวมกฎเฉพาะ เช่น ห้ามอยู่เวรติดกัน หรือค่าล่วงเวลา 1.5 ของพนักงานสั่งการ — แอดมินแก้ไขทีละช่องเองได้หลังสุ่ม ถ้าต้องการกฎเพิ่มเติมแจ้งได้ จะช่วยปรับ logic ให้

## ขั้นตอนที่ 1: สร้างโปรเจกต์ Firebase (ฟรี)

1. ไปที่ https://console.firebase.google.com → **Add project** → ตั้งชื่อโปรเจกต์ (ไม่ต้องเปิด Google Analytics ก็ได้)
2. เมนูซ้าย **Build → Authentication** → กด **Get started** → เลือกแท็บ **Sign-in method** → เปิดใช้งาน **Email/Password**
3. เมนูซ้าย **Build → Firestore Database** → **Create database** → เลือก **Start in production mode** → เลือก location ที่ใกล้ที่สุด (เช่น asia-southeast1)
4. หลังสร้างเสร็จ ไปแท็บ **Rules** แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์ `firestore.rules` ในโปรเจกต์นี้ไปวางทับ แล้วกด **Publish**
5. กลับไปที่ **Project settings** (รูปเฟือง) → เลื่อนลงหา **Your apps** → กดไอคอน **</>** (Web) → ตั้งชื่อ app → จะได้ค่า config มาชุดหนึ่ง หน้าตาแบบนี้:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```

## ขั้นตอนที่ 2: ใส่ค่า config ลงในโค้ด

เปิดไฟล์ `js/firebase-config.js` แล้วแทนที่ค่าใน `firebaseConfig` ด้วยค่าที่ได้จากขั้นตอนที่ 1
และเปลี่ยนค่า `ADMIN_SETUP_KEY` เป็นรหัสลับของคุณเอง (ใช้ตอนสมัครบัญชีแอดมินคนแรกเท่านั้น อย่าบอกใคร):

```js
export const ADMIN_SETUP_KEY = "รหัสลับของหน่วยงานคุณ";
```

## ขั้นตอนที่ 3: อัปโค้ดขึ้น GitHub

```bash
cd shift-scheduler
git init
git add .
git commit -m "ระบบจัดเวรพนักงาน"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/<ชื่อ repo>.git
git push -u origin main
```

(สร้าง repo เปล่าบน GitHub ก่อนจากปุ่ม **New repository** แล้วคัดลอกลิงก์มาใช้แทน `<...>` ด้านบน)

## ขั้นตอนที่ 4: เปิด GitHub Pages (ฟรี)

1. ในหน้า repo บน GitHub → **Settings → Pages**
2. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
3. Branch เลือก **main** และโฟลเดอร์เลือก **/(root)** → กด **Save**
4. รอ 1-2 นาที จะได้ลิงก์เว็บแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## ขั้นตอนที่ 5: อนุญาตโดเมนใน Firebase

กลับไปที่ Firebase Console → **Authentication → Settings → Authorized domains** → กด **Add domain**
แล้วใส่โดเมนของ GitHub Pages เช่น `<ชื่อผู้ใช้>.github.io` (ไม่ต้องใส่ https:// หรือ path ต่อท้าย)

## ขั้นตอนที่ 6: เริ่มใช้งาน

1. เปิดลิงก์เว็บของคุณ → แท็บ **สมัครสมาชิก** → ติ๊ก **สมัครเป็นแอดมิน** → กรอก **รหัสตั้งค่าระบบ** ที่ตั้งไว้ในขั้นตอนที่ 2 → กรอกอีเมล/รหัสผ่าน → สมัคร
2. เข้าสู่ระบบด้วยบัญชีแอดมิน → เมนู **จัดการพนักงาน** → เพิ่มชื่อ-รหัสพนักงานตามกลุ่มต่างๆ ให้ครบ (ระบบสร้าง 5 กลุ่มเริ่มต้นให้อัตโนมัติตามไฟล์ต้นฉบับ)
3. เมนู **ปฏิทิน / วันหยุด** → กด **โหลดวันหยุดราชการ** ของปีที่ต้องการ (ใส่เป็น พ.ศ.) และเพิ่มวันหยุดพิเศษได้ตามต้องการ
4. เมนู **จัดตารางเวร** → เลือกกลุ่ม → เลือกเดือน → ตรวจสอบ "จำนวนช่วงเวร/วัน" ให้ถูกต้องแล้วกด **บันทึกค่านี้** → กด **สุ่มหมุนเวรอัตโนมัติ** → แก้ไขทีละช่องได้จาก dropdown ในตาราง
5. แจ้งรหัสพนักงานให้พนักงานแต่ละคนไปสมัครสมาชิกเองที่หน้าเข้าสู่ระบบ (แท็บสมัครสมาชิก โดยไม่ติ๊กแอดมิน) เพื่อดูตารางเวรของตัวเองในเมนู **ตารางเวรของฉัน**

## โครงสร้างไฟล์
```
shift-scheduler/
├── index.html          หน้าล็อกอิน/สมัครสมาชิก
├── app.html             หน้าหลักของระบบ (เมนูตามสิทธิ์)
├── css/style.css
├── js/
│   ├── firebase-config.js   ← แก้ค่า config และรหัสลับตรงนี้
│   ├── auth.js
│   ├── staff.js
│   ├── holidays.js
│   ├── schedule.js
│   └── app.js
└── firestore.rules      ← นำไปวางใน Firebase Console > Firestore > Rules
```

มีข้อสงสัยหรืออยากให้ปรับ logic การจัดเวร (เช่น ห้ามอยู่เวรติดกัน, กฎ 1.5 ของพนักงานสั่งการ, จำกัดจำนวนคนสูงสุดต่อกะ) แจ้งเพิ่มได้เลยครับ
